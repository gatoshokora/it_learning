# IT Learning

IT初心者向けのクイズ学習アプリです。

Python・SQLite・GitなどのIT分野からカテゴリーと難易度を選択すると、
Gemini APIを利用して問題を自動生成し、クイズ形式で学習できます。

ユーザー登録・ログイン機能を実装しており、
ログイン状態に応じたアクセス制御も行っています。

## 概要

ITの基礎知識をクイズ形式で学習することを目的として開発しました。
問題はGemini APIを利用して生成し、1回のクイズでは同じ問題文が出題されないようにしています。

## 主な機能

- ユーザー新規登録
- ログイン・ログアウト
- パスワードのハッシュ化
- saltを利用したパスワード保護
- ログイン状態の管理
- ログインユーザーのみクイズ機能を利用可能
- Python・SQLite・Gitのカテゴリー選択
- 初級・中級・上級の難易度選択
- Gemini APIによる問題生成
- クイズ5問の出題
- 正解数の集計
- 同一クイズ内での問題重複防止
- 解答後の解説表示

## 認証・セキュリティ

パスワードはデータベースに平文で保存せず、
PBKDF2-HMAC（SHA-256）を使用してハッシュ化しています。

また、ユーザーごとにランダムなsaltを生成し、
ハッシュ値とsaltをデータベースに保存しています。

ログイン時には、データベースから取得したsaltを使用して
入力されたパスワードを再度ハッシュ化し、保存されているハッシュ値と比較しています。

## アクセス制御

ログイン状態に応じて利用できる機能を制御しています。

#### 未ログイン

* 新規登録：利用可能
* ログイン：利用可能
* クイズ：利用不可
* ログアウト：利用不可

#### ログイン済み

* クイズ：利用可能
* ログアウト：利用可能

また、画面上のボタンを非表示にするだけではなく、
app.py でクイズ関連ページへのアクセス時にもログイン状態を確認しています。

## 工夫した点

#### パスワードを平文で保存しない

ユーザーのパスワードをそのままデータベースに保存せず、
PBKDF2-HMACとsaltを使用してハッシュ化しています。

#### ログイン状態に応じたアクセス制御

ログイン状態をst.session_stateで管理し、
未ログインユーザーがクイズ機能を利用できないようにしています。

#### 問題の重複防止

現在のクイズで出題した問題文をst.session_stateにリストとして保存し、
次の問題を生成するときにGemini APIへ渡しています。

#### バージョンごとの開発

機能を一度に追加するのではなく、

* Ver1：基本的なクイズ機能
* Ver2：ユーザー認証
* Ver3：アクセス制御

と段階的に機能を追加しました。

各バージョンの完成時点をGitで管理しています。
